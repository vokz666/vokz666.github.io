Privacy Policy: Kicks Uploader

Last updated: November 1, 2026

Kicks Uploader ("the app") is a private tool used by the owner of the YouTube channels Anhel Kicks and Vokz Kicks to upload videos to those channels. It is not offered to the public.

Data the app accesses

The app requests one Google OAuth permission: https://www.googleapis.com/auth/youtube.upload, which allows it to upload videos and set their title, description, tags and publishing time on the authorized channel. The app does not read, collect or store any other Google account data, such as email, contacts, watch history, comments or analytics.

How the data is used

The OAuth access token is used only to upload videos created by the channel owner to the channel owner's own YouTube channels. Nothing else is done with it.

Storage and security

OAuth credentials (client secret and refresh tokens) are stored only as encrypted secrets in the owner's private GitHub repository and are used only by its automated upload job. They are not stored anywhere else and are never published.

Sharing

The app does not sell, share, transfer or disclose any user data to third parties, and does not use it for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google Account permissions page. After revocation, the stored refresh token stops working and is deleted from the repository secrets.
