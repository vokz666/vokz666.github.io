Kicks Uploader

A private tool that publishes short football "Stop Challenge" videos to our own YouTube channels.

What it does

Kicks Uploader takes short videos that we create ourselves and uploads them, with a title, description and publishing schedule, to these YouTube channels operated by us:

  • Anhel Kicks
  • Vokz Kicks

The tool is used only by the owner of these channels. It is not offered to the public and does not access anyone else's account.

Google and YouTube data

The tool uses the YouTube Data API with the single permission needed to upload videos to our own channels. See the Privacy Policy for details.
